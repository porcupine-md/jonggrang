# Landing page minimalist baseline

## Product and UX rationale

Use this baseline when a page must explain one proposition and earn one action.
The first viewport establishes audience, outcome, and evidence; later sections
remove objections rather than repeat the headline.

## Visual direction and baseline

Use a quiet canvas, strong type hierarchy, short line lengths, and one accent.
Let spacing separate arguments. Prefer asymmetry created by copy and evidence,
not decorative floating objects.

## Components and layout patterns

- **Hero:** one claim, one supporting paragraph, one primary action, and one
  concrete proof item. Do not place a feature-card grid above the proof.
- **Proof strip:** use measured outcomes, recognizable customers, or a product
  artifact. Avoid unsupported superlatives.
- **Feature narrative:** alternate concise explanation with a real screenshot or
  diagram. Cards are reserved for genuinely comparable choices.
- **Final action:** repeat the same commitment as the hero; do not introduce a
  new funnel at the bottom.

## Interaction, responsive, and accessibility rules

Preserve reading order on narrow screens. Keep calls to action descriptive.
Images need meaningful alternatives; decorative media stays silent. Motion may
explain a transition but must not make copy wait to become readable.

## Rules summary

- One page, one conversion.
- Proof before repetition.
- Typography and whitespace carry the hierarchy.
- No ornamental gradients, floating blobs, or generic feature-card wallpaper.
